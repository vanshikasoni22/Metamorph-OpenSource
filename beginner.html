What Contrib reads

  • repos Languages, topics and project types you have built
  • events How recently and how often you push code
  • pulls Pull requests you have already opened or merged elsewhere
  • tests Whether your repos use tests, CI and linters

Everything Contrib concludes about you cites one of these sources. Anything it cannot see is marked Unknown.
